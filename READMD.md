## Features

- Daily entry: base money + tips earned
- Auto-rollup by month (and year)
- Reconciliation: tips _received_ vs tips _unpaid_ by manager

## Target Users

- Nail tech

## MVP

### v1

- Daily entry screen: date auto-filled, input base money + tip
- Auto-save at day's end (or on manual submit)
- History log
- Monthly/yearly summary
- Tip reconciliation: "tips reported by salon" vs "tips actually received" → unpaid tip alert
- Edit/delete past entries (typos happen)

### v1.1

- Push noti reminder
- Simple charts (weekly/monthly trend)
- Export to CSV/PDF (for taxes or disputes with employer)
- PIN/biometric lock (financial data, personal device)

## Tech Stack

- React Native, Expo, TypeScript
- Golang
